# Smart Movie Recommendation System

This project is a modern web application that provides personalized movie recommendations using the K-Nearest Neighbors (KNN) algorithm. The user interface is built with Streamlit.

---

## Features

* **Advanced Machine Learning Model:** Identifies movies closest to the user's taste using the cosine distance metric.
* **Detailed Movie Insights:** Instantly displays genres and similarity percentages (%) for the recommended movies.

---

## Technologies Used

* **Python**
* **Streamlit** (UI Framework)
* **Pandas** (Data manipulation and analysis)
* **Scikit-Learn** (KNN model and similarity calculations)
